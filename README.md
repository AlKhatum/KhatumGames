# Khatum Games

Сайт проекта с интерактивной «Картой мира после Великого Потопа»: https://alkhatum.github.io/KhatumGames/

## Два режима карты

**Просмотр (для всех).** Карту можно двигать и приближать. Клик по стране показывает её флаг и название в легенде. Во вкладке «Слои» легенды включаются и выключаются слои, а дороги можно подсветить. Редактирования нет.

**ГМ (по паролю).** Кнопка «🔒 Вход ГМ» в углу карты. После входа доступно:

- **Кисть, Карандаш, Ластик, Заливка, Пипетка.** Рисуют территорию страны прямо по карте. Границы пересчитываются в плавные контуры. Опции: «Только суша», «Не трогать соседей». Размер кисти меняется клавишами `[` и `]`, Alt+клик берёт страну с карты, правая кнопка мыши двигает карту.
- **Города.** Значок и подпись перетаскиваются: потяните значок, чтобы двигать город целиком, или подпись, чтобы двигать её отдельно. Двойной клик переименовывает город. Инструмент «Город» добавляет новый.
- **Подписи и отметки.** Отметки бывают 10 типов. Инструмент «Удалить» стирает объект.
- **Легенда.** В легенде можно править названия стран, цвет и флаг, создавать и удалять страны.
- **Отмена и повтор:** Ctrl+Z / Ctrl+Y. Неопубликованная работа сохраняется черновиком в браузере ГМа.
- **«Опубликовать».** Отправляет правки одним коммитом в этот репозиторий: `data/map.json`, `data/territories.png` и флаги. Сайт обновится примерно через минуту.

Для публикации нужен токен GitHub (кнопка «GitHub»): fine-grained token с правом *Contents: Read and write* только для этого репозитория. Токен хранится только в браузере ГМа.

> Пароль закрывает интерфейс редактирования. Сохранить правки на сайт без токена GitHub невозможно, поэтому настоящая защита — это токен.

## Данные

| Файл | Что это |
|---|---|
| `data/territories.png` | Территории стран: оттенок серого = id страны, 4087×3554 |
| `data/map.json` | Названия, цвета, флаги, подписи стран, города, подписи, отметки |
| `data/config.json` | Репозиторий для публикации и хэш пароля ГМа (PBKDF2-SHA256) |
| `assets/map/*.png` | Слои из PSD: суша, гидрография, дороги, ЖД, городские зоны, обводка, текстура океана |

## Источники

- `Первая Карта (Использовать как основу).psd` — основа. Из неё взяты 139 стран (цвета из эффекта «Наложение цвета»), рельеф, гидрография, транспорт и обводка.
- `Текст.psd`, папка «Информация» — 753 значка городов и 752 подписи. Каждая подпись привязана к своему значку.
- Шаблон — тёмно-синий океан с сеткой квадратов и мазками, широкий тонкий шрифт (на сайте Unbounded).
- «ЗНАЧОК ГОРОДА» — образец значка: тёмный круг с белым силуэтом кварталов.

Фон сайта — видео YouTube «Narvent — Her Eyes». Звук включается первым кликом или кнопкой «Звук».
