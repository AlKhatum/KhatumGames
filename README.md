# Khatum Games

Сайт проекта с интерактивной «Картой мира после Великого Потопа»: https://alkhatum.github.io/KhatumGames/

## Глобус, линейка и циркуль

- **Карта / Глобус** (переключатель в левом верхнем углу). Глобус — ортографическая проекция: шар можно вращать мышью и приближать колесом. На нём видны те же слои, что на карте (рельеф, реки, дороги с подсветкой, ЖД, городские зоны, провинции, границы, города и названия), и переключатели легенды работают так же. Клик по стране или провинции показывает её в легенде.
- **Орбиты** (панель на глобусе). 11 спутников: станции «Ковчег» (аналог МКС, 418 км, 51,6°), «Ковчег-Восток», «Новый Мир», метеоспутник, спутники наблюдения, телескоп, «Молния-Ковчег» на вытянутой орбите, три навигационных, геостационарный «Страж-ГСО». Движение моделируется по законам Кеплера с учётом вращения Земли. Есть траектории (задняя часть пунктиром), названия, слежение за спутником, скорость времени (пауза, ×1, ×60, ×600). Клик по спутнику показывает его высоту, скорость, период и точку под ним.
- **ГМ и спутники.** В панели «Орбиты» ГМ добавляет («+ Спутник»), правит (✎) и удаляет (✕) спутники. Доступны круговая, эллиптическая и геостационарная орбиты; высота, наклонение, долгота узла и начальное положение задаются в форме. Типы спутников («+ Тип», раздел «Типы спутников») тоже можно создавать: название, цвет, значок (станция, точка, ромб, треугольник, квадрат). Всё публикуется кнопкой «Опубликовать» и отменяется Ctrl+Z.
- **Линейка и Циркуль** (панель внизу слева) доступны всем. Линейка меряет маршрут по точкам, циркуль строит окружность заданного радиуса. Расстояния считаются по поверхности Земли (радиус 6371 км). Карта — проекция Меркатора на весь мир, откалиброванная по 19 реальным городам: ошибка около 30 км, Москва — Париж по карте 2498 км при реальных 2486.

## Провинции

3656 провинций, областей, штатов и департаментов построены по реальным административным границам (Natural Earth, admin-1, public domain). Их перенесли на карту той же проекцией и обрезали по берегам после Потопа: затопленные регионы исчезли, новая суша отошла ближайшему региону. Каждая провинция привязана к игровой стране, которой принадлежит большая её часть.

- В слоях есть «Провинции» (пунктирные границы, с подсветкой) и «Названия провинций» (появляются при приближении).
- Клик по карте показывает в легенде и страну, и провинцию.
- ГМ рисует провинции той же кистью, карандашом, ластиком и заливкой (переключатель «Страны / Провинции» на панели кисти), создаёт новые («+ Провинция») и переименовывает их в легенде или двойным кликом по названию.

## Два режима карты

**Просмотр (для всех).** Карту можно двигать и приближать. Клик по стране показывает её флаг и название в легенде. Во вкладке «Слои» легенды включаются и выключаются слои. Названия стран («Страны»), границы и дороги можно подсветить. В группе «Дороги»: главные автострады, основные магистрали, второстепенные дороги, железные дороги. Редактирования нет.

**ГМ (по паролю).** Кнопка «🔒 Вход ГМ» в углу карты. После входа доступно:

- **Кисть, Карандаш, Ластик, Заливка, Пипетка.** Рисуют территорию страны прямо по карте. Границы пересчитываются в плавные контуры. Опции: «Только суша», «Не трогать соседей». Размер кисти меняется клавишами `[` и `]`, Alt+клик берёт страну с карты, правая кнопка мыши двигает карту.
- **Города.** Значок и подпись перетаскиваются: потяните значок, чтобы двигать город целиком, или подпись, чтобы двигать её отдельно. Двойной клик переименовывает город. Инструмент «Город» добавляет новый.
- **Подписи.** Инструмент «Подпись» добавляет надпись, «Удалить» стирает объект.
- **Легенда.** В легенде можно править названия стран, цвет и флаг, создавать и удалять страны.
- **Отмена и повтор:** Ctrl+Z / Ctrl+Y. Неопубликованная работа сохраняется черновиком в браузере ГМа.
- **«Опубликовать».** Отправляет правки одним коммитом в этот репозиторий: `data/map.json`, `data/territories.png` и флаги. Сайт обновится примерно через минуту.

Для публикации нужен токен GitHub (кнопка «GitHub»): fine-grained token с правом *Contents: Read and write* только для этого репозитория. Токен хранится только в браузере ГМа.

> Пароль закрывает интерфейс редактирования. Сохранить правки на сайт без токена GitHub невозможно, поэтому настоящая защита — это токен.

## Данные

| Файл | Что это |
|---|---|
| `data/territories.png` | Территории стран: оттенок серого = id страны, 4087×3554 |
| `data/provinces.png` | Провинции: id = R + G·256, 4087×3554 |
| `data/map.json` | Названия, цвета, флаги, подписи стран, провинции, города, подписи |
| `js/geo.js` | Проекция карты (Меркатор), расстояния по сфере |
| `js/sats.js` | Модель орбит (спутники и их типы хранятся в `data/map.json`) |
| `data/config.json` | Репозиторий для публикации и хэш пароля ГМа (PBKDF2-SHA256) |
| `assets/map/*.png` | Слои из PSD: суша, гидрография, дороги, ЖД, городские зоны, текстура океана |

## Источники

- `Первая Карта (Использовать как основу).psd` — основа. Из неё взяты 139 стран (цвета из эффекта «Наложение цвета»), рельеф, гидрография и транспорт (слой Unknown объединён со второстепенными дорогами).
- `Текст.psd`, папка «Информация» — 753 значка городов и 752 подписи. Каждая подпись привязана к своему значку.
- Шаблон — тёмно-синий океан с сеткой квадратов и мазками, широкий тонкий шрифт (на сайте Unbounded).
- «ЗНАЧОК ГОРОДА» — образец значка: тёмный круг с белым силуэтом кварталов.

Фон сайта — видео YouTube «VXLLAIN, iGRES — Revival (Slowed + Reverb)». Звук включается первым кликом или кнопкой «Звук».
