# Khatum Games

Сайт проекта с интерактивной «Картой мира после Великого Потопа».

Открыть: https://alkhatum.github.io/KhatumGames/ (после включения GitHub Pages: Settings → Pages → Deploy from branch → `main` / root).

## Что умеет карта

- **Слои** (панель справа): включение/выключение каждого слоя из PSD. Группа «Дороги» (Major Highway, Secondary Highway, Road, Unknown) — каждый слой можно сделать видимым и **подсветить** кнопкой «Подсветка», или все сразу.
- **Границы**: инструмент «Границы» — выберите страну, тяните вершины, клик по контуру добавляет вершину, Alt+клик / правый клик удаляет.
- **Новые территории и линии границ**: инструменты «Территория» и «Линия».
- **Названия**: двойной клик по любой стране, городу, подписи или отметке — переименовать. Инструмент «Название» добавляет новые подписи.
- **Отметки**: 10 типов — Столица, Крепость, Порт, Поле битвы, Руины, Храм, Рудник, Лагерь выживших, Маяк, Затопленный город.
- **Легенда карты**: флаг (заглушка, по клику можно загрузить картинку) и название выбранной страны, цвет.
- **Отмена / повтор**: Ctrl+Z / Ctrl+Y. Правки хранятся в браузере; есть экспорт/импорт JSON.

## Источники

- `Заказ на глобус.psd` — подложка, страны (векторизованы в `data/countries.js`), гидрография, транспорт, обводка.
- `Текст.psd` — подписи 752 городов (`data/cities.js`) и значки городов.
- Стиль океана (тёмно-синий с сеткой-квадратами) — по шаблону.

Фон — видео YouTube «Narvent — Her Eyes» (автовоспроизведение без звука; звук включается первым кликом или кнопкой «Звук»).
